# Sistema de liquidación - Empresa de mensajería
Este sistema esta diseñado para facilitar la liquidación semanal de una empresa de mensajería. Su objetivo es optimizar los procesos 
de pago de sus empleados y generar sus reportes según la regla de negocio. 
## Tecnología
  - Elixir/OTP 29
  - Erlang 1.20.2
## Instalación y configuración:
 Este proyecto esta desarrollado en **Elixir** y utiliza la máquina virtual de **Erlang**. 
 - Instrucciones de instalación:
### Windows
  Ejecuta el siguiente comando en PowerShell como administrador utilizando [chocolatey]:
  ```powershell
    choco install elixir
  ```
  ### Linux
  Ejecuta el siguiente comando en la terminal de tu preferencia y según tu distrubución,
  actualiza los repositorios del sistema antes de ejeceuta el comando:
  - Ubuntu:
  ```bash
    sudo add-apt-repository ppa:rabbitmq/rabbitmq-erlang sudo apt update sudo apt install git elixir erlang
  ```
  ### Más información de instalación:
  https://elixir-lang.org/install/

  ## Verificación de instalación
  ```bash
    elixir --version
  ```
